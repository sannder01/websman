# PIXEL — 4_6

Сайт компьютерного клуба PIXEL: информация о клубе и залах, каталог игр, расчёт стоимости посещения и отправка заявок администратору в Telegram.

## Функционал

- Каталог игр с поиском по названию и фильтром по жанру.
- Перенос выбранной игры в форму посещения.
- Выбор зала, ПК, даты, времени и количества игроков.
- Расчёт длительности и стоимости посещения по почасовым и пакетным тарифам.
- Корзина пакетов: добавление, изменение количества, удаление и расчёт общей суммы.
- Проверка данных формы, сводка визита и отправка заявки администратору в Telegram. Места подтверждает администратор.
- Сохранение выбранных пакетов и параметров визита между страницами.
- Информация о залах и ответы на частые вопросы.
- **Дополнительная функция 1: избранные игры.** Добавление и удаление игр, сохранение на устройстве, фильтр «Только избранное» вместе с поиском и жанром, очистка списка.
- **Дополнительная функция 2: сравнение залов.** Сопоставление оборудования и вместимости, расчёт почасовой суммы для компании, разница в цене и перенос параметров в план визита.

## Задание jQuery

Используется **jQuery 3.7.1, полная сборка** из `code.jquery.com`: slim-сборка не содержит нужных эффектов. На пяти основных страницах CDN подключён с `defer` перед `main.js` и скриптами страниц. Для загрузки библиотеки нужен интернет; её целостность проверяется SRI.

Три существующие функции переписаны с комментариями для сравнения:

| Функция | Реализация | Что поменялось |
| --- | --- | --- |
| Каталог и избранное | `demofinal/js/games.js` | `.find()`, `.clone()`, `.append()`, фильтры, `.on()` вместо прямого DOM и отдельных слушателей каждой кнопки |
| Показ и скрытие блоков каталога | `demofinal/js/main.js`, `PixelMain.show()` | Цепочка `.prop().toggleClass()` вместо `hidden` и `classList`; используется каталогом |
| Проверка формы и интерфейс плана | `demofinal/js/booking.js` | `.val()`, `.on()`, `.addClass()/.removeClass()`, отдельное сообщение у каждого поля; расчёт и отправка сохранены |

Исходные версии всех трёх файлов из коммита `66c2e3e` находятся в `demofinal/js/old-js-version.js`. Этот файл **не подключён** ни к одной странице.

- Каталог использует селекторы по id, классу, тегу, атрибуту, `:checked` и `:first`; обход `.find()`, `.closest()`, `.parent()`, `.siblings()`, `.each()`; цепочки из трёх и более методов.
- Список сохранённых игр `#games-saved-list` целиком создаётся из массива в коде. Родители списков принимают делегированные клики: обработчики работают после поиска и пересоздания карточек. В обработчиках используется `$(this)`.
- На странице помощи вопросы раскрываются через `.slideDown()` и `.slideUp()`. Подтверждение заявки появляется через `.fadeIn()`, исправленная ошибка исчезает через `.fadeOut()`. Есть длительности, callback, остановка очереди быстрых кликов и учёт уменьшенного движения.
- На отправке проверяются все поля, обрезаются пробелы, проверяются телефон и необязательный e-mail, созданный в коде. Ошибка отмечается классом `is-invalid` и сообщением рядом с полем, очищается при исправлении. `required`, типы и ограничения полей сохранены. Успех показывается после ответа сервера, затем форма очищается. Контакты не сохраняются в хранилищах браузера.
- Сервер повторно проверяет контакты, параметры и стоимость. Проверку браузера можно обойти, поэтому она не заменяет серверную.


## Запуск

Требуется Python 3.10 или новее. Установка сторонних зависимостей не нужна.

1. Склонируйте репозиторий и перейдите в его папку:

   ```powershell
   git clone https://github.com/sannder01/websman.git
   cd websman
   ```

2. Создайте файл `env/.env` по шаблону `.env.example`. Укажите `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` и `PUBLIC_ORIGIN=http://127.0.0.1:8898`. Инструкция подключения бота — [TELEGRAM_SETUP.md](TELEGRAM_SETUP.md).

3. Запустите сервер из корня проекта:

   ```powershell
   python booking_server.py --port 8898
   ```

4. Откройте [http://127.0.0.1:8898/index.html](http://127.0.0.1:8898/index.html).

Для локальной демонстрации без настройки Telegram:

```powershell
python booking_server.py --dry-run --port 8899
```

Откройте [игры](http://127.0.0.1:8899/games.html) или [залы](http://127.0.0.1:8899/rooms.html). В тестовом режиме сообщения администратору не отправляются.

## Проверка

```powershell
python tests/check_coursework.py
python -m unittest discover -s tests -p "test_*.py"
npm ci
npx playwright install chromium
node --test tests/test_packages.cjs
node tests/individual-features-browser.cjs
node tests/jquery-browser.cjs
node tests/booking-delivery-browser.cjs
```

Браузерные тесты используют Playwright и запущенный тестовый сервер на порту 8899 (`python booking_server.py --dry-run --port 8899`). Тест jQuery проверяет делегирование, все страницы и перенаправления на 375/1440 px, эффекты, клавиатуру, проверку полей, один тестовый запрос и очистку формы. Тест дополнительных функций также проверяет 768 px и сбои хранилища. Для поддерживающих этот параметр тестов можно задать `PIXEL_BROWSER_EXECUTABLE_PATH` с путём к установленному Chrome.
