# PIXEL — 4_6

Сайт компьютерного клуба PIXEL: информация о клубе и залах, каталог игр, расчёт стоимости посещения и отправка заявок администратору в Telegram.

## Функционал

- Каталог игр с поиском по названию и фильтром по жанру.
- Перенос выбранной игры в форму посещения.
- Выбор зала, ПК, даты, времени и количества игроков.
- Расчёт длительности и стоимости посещения по почасовым и пакетным тарифам.
- Корзина пакетов: добавление, изменение количества, удаление и расчёт общей суммы.
- Проверка данных формы, сводка визита и отправка заявки администратору в Telegram. Места подтверждает администратор.
- Сохранение выбранных пакетов и параметров визита между страницами.
- Информация о залах и ответы на частые вопросы.
- **Дополнительная функция 1: избранные игры.** Добавление и удаление игр, сохранение на устройстве, фильтр «Только избранное» вместе с поиском и жанром, очистка списка.
- **Дополнительная функция 2: сравнение залов.** Сопоставление оборудования и вместимости, расчёт почасовой суммы для компании, разница в цене и перенос параметров в план визита.

## Запуск

Требуется Python 3.10 или новее. Установка сторонних зависимостей не нужна.

1. Склонируйте репозиторий и перейдите в его папку:

   ```powershell
   git clone https://github.com/sannder01/websman.git
   cd websman
   ```

2. Создайте файл `env/.env` по шаблону `.env.example`. Укажите `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` и `PUBLIC_ORIGIN=http://127.0.0.1:8898`. Инструкция подключения бота — [TELEGRAM_SETUP.md](TELEGRAM_SETUP.md).

3. Запустите сервер из корня проекта:

   ```powershell
   python booking_server.py --port 8898
   ```

4. Откройте [http://127.0.0.1:8898/index.html](http://127.0.0.1:8898/index.html).

Для локальной демонстрации без настройки Telegram:

```powershell
python booking_server.py --dry-run --port 8899
```

Откройте [игры](http://127.0.0.1:8899/games.html) или [залы](http://127.0.0.1:8899/rooms.html). В тестовом режиме сообщения администратору не отправляются.

## Проверка

```powershell
python tests/check_coursework.py
node --test tests/test_packages.cjs
node tests/individual-features-browser.cjs
```

Браузерный тест использует установленный Playwright и запущенный тестовый сервер на порту 8899. Если Chromium не установлен для Playwright, задайте `PIXEL_BROWSER_EXECUTABLE_PATH` с путём к установленному Chrome. Тест проверяет новые сценарии, клавиатуру, сохранение и ширины 375/768/1440 px.

Архив не содержал историю Git. Первый коммит сохраняет исходные файлы архива, следующий - дополнительные функции и документацию. Старые теги и даты коммитов не создавались задним числом.
